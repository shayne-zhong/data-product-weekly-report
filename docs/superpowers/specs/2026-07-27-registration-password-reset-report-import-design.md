# 优化注册、密码重置和周报待办导入

本文定义独立注册页、管理员密码重置和周报待办导入修复。目标是让成员完成注册后重新登录，让管理员安全地处理忘记密码，并让每份总结读取自身周期内的待办。

## 目标和范围

本次改动服务部门成员和后台管理员，包含以下内容：

- 将弹窗注册改为独立注册页
- 注册成功后返回登录首页，不自动登录
- 在登录页增加忘记密码入口
- 允许后台管理员为已注册成员重置密码
- 简化登录保持时间提示
- 修复总结页面无法读取对应周期待办的问题

本次不增加手机号、邮箱、验证码或强制修改密码流程，也不修改现有部门和业务数据。

## 登录和注册体验

登录首页保持现有视觉语言，并使用居中聚焦卡片。表单包含账号和密码，辅助操作包含 **注册账号** 和 **忘记密码**。

首页将现有说明改为“保持登录：{后台设置时间}”。前端根据后台返回的分钟数显示分钟、小时或天，不再解释登录状态的计算规则。

点击 **注册账号** 后，页面切换到独立注册视图。注册视图只处理注册，包含账号、姓名、密码、确认密码、**完成注册** 和 **返回登录**。页面不显示登录表单，也不打开弹窗。

注册成功后，客户端不得保存用户令牌或进入工作台。页面先显示“注册成功，请重新登录”，约 2 秒后返回登录首页，并带入刚注册的账号。用户必须输入密码再次登录。

## 忘记密码和管理员重置

点击 **忘记密码** 后，页面显示管理员重置说明和 **返回登录**。该页面不查询账号，避免泄露成员账号是否存在。

后台 **账号管理** 为已注册成员显示 **重置密码**。管理员输入并确认至少 6 位的新密码后提交。未注册成员不显示该操作。

服务端只接受有效的后台短期令牌。重置时生成新的随机盐和密码摘要，不保存明文。重置完成后，服务端删除该成员的全部现有会话。新密码立即生效，用户下次登录时不强制修改密码。

## 周报待办导入

现有问题来自数据周期错位。页面打开历史总结时只加载总结内容，导入窗口仍读取首页当前周的 `tasks`。历史总结和非当前周期总结因此无法获得对应待办。

服务端增加按开始日期和结束日期查询任务的受保护接口。接口仅返回当前登录成员所属部门的数据，并筛选任务所属周与查询周期有交集的记录。

打开 **导入待办** 后，客户端按当前总结的开始日期和结束日期请求候选任务。窗口先显示“正在加载待办…”，成功后默认筛选当前报告模块，并允许切换到其他模块。

候选列表包含该周期内当前模块的全部待办。月报和季报汇总日期范围内各周任务。加载失败时显示错误和 **重新加载**，空列表显示“当前周期和模块暂无可导入待办”。

导入继续使用现有文本格式、重复判断、序号和自动保存逻辑。切换报告小节只改变导入文本格式，不重新请求候选任务。

## 接口和数据流

本次新增两个受保护操作：

- `POST /api/admin/users/{username}/reset-password`：后台管理员重置已注册成员密码
- `GET /api/tasks?startDate={date}&endDate={date}`：成员查询当前部门在日期范围内的任务

注册接口保留现有账号清单和部门校验，但注册成功只返回成功状态和公开用户信息，不创建会话。登录接口继续创建会话，并按后台设置计算到期时间。

前端为认证区域维护 `login`、`register` 和 `forgot-password` 三个视图状态。总结导入窗口维护 `idle`、`loading`、`success` 和 `error` 四个加载状态。

## 错误处理

注册页在客户端校验必填项、两次密码一致和密码长度。服务端继续执行相同的安全校验，并按后台成员清单确定姓名和所属部门。接口返回现有账号、未配置账号或停用部门错误。

密码重置接口拒绝无效后台令牌、未注册账号和不足 6 位的密码。前端提交期间禁用按钮，成功后关闭对话框并显示结果。

任务查询拒绝无效日期和结束日期早于开始日期。接口错误不会清空周报内容，也不会回退到首页当前周任务。

## 测试和验收

自动化测试覆盖以下行为：

- 注册成功不返回令牌，也不创建会话
- 注册页成功后返回登录视图并带入账号
- 管理员可重置已注册成员密码
- 旧密码和旧会话在重置后失效
- 新密码可正常登录
- 非管理员无法重置密码
- 日期范围查询只返回当前部门和对应周期任务
- 月报和季报可汇总范围内各周任务
- 导入窗口显示加载、空数据和失败状态
- 当前报告模块默认选中，并可切换其他模块
- 首页显示格式化后的后台登录保持时间
