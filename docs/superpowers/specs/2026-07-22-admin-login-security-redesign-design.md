# 后台、登录与密钥管理优化设计

## 背景

现有后台将多个配置区纵向堆叠在同一页面，信息密度不均、滚动距离长，编辑状态和保存反馈不够清晰。普通用户访问业务接口前还需要输入协同口令，增加了不必要的登录步骤。AI API 密钥只能通过部署环境变量配置，管理员无法在后台直接维护。

本次优化不改变已有部门、用户、任务、目标和周报数据，只重做后台交互、普通用户登录入口及服务端密钥管理。

## 目标

1. 将后台改为易定位、易编辑、易扩展的设置中心。
2. 首次访问显示独立登录页，普通用户只使用账号和密码登录。
3. 从浏览器和业务 API 中移除系统同步密钥。
4. 允许管理员在后台安全配置、测试、替换和清除 AI API 密钥。
5. 保留独立管理员身份，并避免每次后台请求重复发送管理员密码。

## 非目标

- 不调整工作台的任务、目标和周报业务流程。
- 不合并普通用户与管理员账号体系。
- 不删除或重建现有业务数据。
- 不引入复杂的角色权限矩阵。

## 页面与交互

### 首次访问登录页

未登录用户访问根路径时只显示独立登录页，不预加载或展示工作台业务内容。桌面端采用品牌介绍与登录表单双栏布局；移动端隐藏品牌介绍区，只保留登录表单。

登录表单只包含账号和密码。注册入口作为次要操作保留，注册仍受后台成员账号清单约束。登录成功后进入工作台；会话过期后返回登录页，并显示明确的过期提示。页面不出现协同口令、系统同步密钥或 AI API 密钥输入。

### 后台设置中心

后台保留独立 `/admin` 入口和独立管理员登录。登录成功后显示设置中心：

- 左侧分类导航：部门管理、项目类型、账号管理、AI 服务、登录策略。
- 右侧编辑区：只显示当前分类，避免整页纵向堆叠。
- 移动端：分类导航折叠为顶部横向切换。
- 新增操作：使用弹窗或明确的独立编辑行。
- 危险操作：删除、清除密钥和停用配置前二次确认。
- 修改反馈：页面显示未保存状态；发生修改后才显示底部保存栏。
- 离开保护：存在未保存修改时，切换路由或关闭页面前提醒。
- 结果反馈：字段校验、保存成功和网络错误显示在对应编辑区，并提供清晰中文说明。

### AI 服务配置

管理员可选择供应商、模型和启用状态，并直接填写 AI API 密钥。已保存的密钥只显示“已配置”和末尾四位，不回传完整内容。支持以下操作：

- 测试连接：使用草稿密钥或当前已保存密钥执行轻量验证。
- 替换：输入新密钥并在保存后替换旧密钥。
- 清除：二次确认后删除已保存密钥并自动停用 AI 功能。

连接测试失败不覆盖当前已生效密钥。

## 身份验证与 API

### 普通用户会话

普通用户登录和注册接口允许匿名提交必要的账号信息。登录成功后返回有过期时间的用户会话令牌。除登录、注册和登录页所需的最小公开配置外，所有业务接口必须验证用户会话令牌。

前端移除协同口令存储、提示框和 `x-report-key` 请求头。服务端不再使用 `REPORT_SYNC_KEY` 保护业务 API。已有用户密码哈希和账号绑定关系保持不变。

### 管理员会话

管理员账号密码仍由部署环境安全配置。后台登录时只提交一次账号密码；验证成功后，服务端签发短期管理员会话令牌。后续后台读取与保存使用该令牌，不再反复发送管理员密码。管理员令牌仅保存在浏览器会话存储中，关闭标签页后失效；服务端同时校验过期时间。

后台配置读写接口必须验证管理员会话。普通用户令牌不能访问后台配置。

## AI 密钥存储

AI API 密钥使用服务端主密钥通过带认证的加密算法加密后写入现有状态存储。加密记录包含版本、随机向量、认证标签和密文，不保存明文。服务端仅在发起 AI 请求或连接测试时短暂解密。

加密主密钥由腾讯云运行环境提供，不写入代码、浏览器或业务状态。若主密钥缺失或格式错误：

- 后台显示安全配置异常。
- 禁止保存新的 AI API 密钥。
- 不回退到明文存储。
- 其他后台配置仍可读取和保存。

公开设置接口只返回 AI 功能是否启用、供应商、模型和是否已配置。管理员设置接口额外返回脱敏尾号，不返回完整密钥或加密载荷。

## 数据兼容与迁移

现有部门、账号、用户、会话、任务、目标和周报数据结构保持兼容。当前 AI 密钥来自环境变量且未写入业务状态；上线后管理员可在新后台录入密钥。过渡期间服务端可只读使用旧环境变量作为已有密钥来源，但后台保存新密钥后以加密记录为准。完整密钥始终不返回浏览器。

`REPORT_SYNC_KEY` 可暂时保留在云环境以便回滚，但新版本不再读取或要求该变量。

## 异常处理

- 登录失败：不区分账号不存在和密码错误，避免泄露账号状态。
- 会话过期：清除本地令牌并返回独立登录页。
- 后台令牌失效：返回后台登录页，未保存草稿不写入服务端。
- 配置校验失败：定位到具体分类和字段，不提交无效状态。
- AI 密钥测试失败：保留当前生效密钥和草稿输入，显示可操作的错误说明。
- 保存冲突或网络失败：保留本地草稿并允许重试。

## 测试与验收

自动化测试覆盖：

- 无协同口令时可以注册、登录并取得用户会话。
- 未登录用户不能读取或修改业务数据。
- 普通用户会话过期后被拒绝并返回登录页。
- 管理员账号密码可换取短期后台令牌，错误或过期令牌不能访问后台设置。
- AI 密钥加密保存，状态存储中不出现明文。
- 管理员接口只返回脱敏尾号，公开接口不返回密钥信息。
- AI 密钥测试、替换和清除符合设计，失败测试不覆盖当前密钥。
- 后台各分类的草稿、校验、未保存提示和保存行为正确。

浏览器验收覆盖：

- 首次打开为独立登录页，登录后进入工作台。
- 页面和请求流程中不再出现协同口令。
- 后台分类导航、单项编辑、危险操作确认和保存反馈可用。
- 桌面端与移动端布局均可操作。
- 生产构建部署到腾讯云后，检查真实服务状态、健康接口、登录链路和受保护业务接口。

## 上线与回滚

上线前执行依赖安全检查、完整自动化测试和生产构建。部署时先配置 AI 密钥加密主密钥，再发布应用。部署后使用真实线上地址完成普通登录、后台登录和配置读取验证。

旧的 `REPORT_SYNC_KEY` 环境变量和旧版本镜像在观察期内保留，仅用于回滚。若新登录或密钥链路异常，回滚应用版本不会修改已有业务数据。
