# 部门目标产物设计

## 目标

为每个部门目标关联一个可替换的当前产物。用户可在目标表中直接查看产物信息、打开预览并下载原文件；目标 Owner 和后台配置的当前部门负责人可上传、替换或删除。

## 范围

- 每个目标最多一个当前产物，新上传成功后替换旧产物。
- 支持 Word、Excel、PPT、PDF、PNG、JPEG、WebP、GIF 和 HTML。
- 单个文件不超过 20 MB。
- 目标在任何状态下均可上传产物。
- 目标切换为“已完成”但没有产物时提示补充，不阻止保存。
- 本期使用本地文件存储，不部署、不接入云对象存储。
- 代码完成并验证后提交并合并到 GitHub。

## 非目标

- 一个目标关联多个产物。
- 产物历史版本、回退和版本对比。
- 在线编辑产物内容。
- 线上部署及云对象存储配置。

## 架构

### 存储边界

新增独立产物存储模块，业务层仅依赖以下能力：写入、读取、检查存在和删除。首个驱动将文件保存到项目数据目录下的专用产物目录；目录中的实际产物必须被 Git 忽略，仅保留目录说明。

部署到无服务器环境时应新增对象存储驱动，不改变目标产物接口、元数据或前端交互。

### 目标数据

每个目标必须拥有稳定 `id`。旧目标缺少 `id` 时，在读取或保存目标时补齐并持久化。

目标的 `artifact` 字段只保存安全元数据：

- `originalName`
- `mimeType`
- `size`
- `storageKey`
- `previewStorageKey`
- `previewMimeType`
- `updatedAt`
- `updatedBy`

目标列表响应不得把内部文件系统路径暴露给前端。

### API

- `POST /api/goals/:goalId/artifact`：以 multipart 上传或替换产物。
- `GET /api/goals/:goalId/artifact/download`：鉴权后下载原文件。
- `GET /api/goals/:goalId/artifact/preview`：鉴权后读取预览内容。
- `DELETE /api/goals/:goalId/artifact`：删除当前产物及其预览。

所有接口要求已登录，并限制在当前部门。上传、替换、删除仅允许后台配置的当前部门负责人（`leaderUsername`），或登录用户姓名/账号与目标 `owner` 匹配；无法匹配 Owner 时仅当前部门负责人可修改。部门内其他登录用户可预览和下载。

## 上传与替换流程

1. 校验登录状态、部门、目标存在性和修改权限。
2. 同时校验扩展名、MIME 类型和 20 MB 大小上限。
3. 使用随机存储键保存原文件，禁止使用用户文件名拼接路径。
4. 图片、PDF直接作为预览；HTML保存原文件并通过沙箱页面展示。
5. Word、Excel、PPT调用 LibreOffice 无界面模式转换为 PDF。转换失败则本次上传失败并清理新文件。
6. 原文件和预览均可用后更新目标元数据。
7. 元数据保存失败时删除新文件并保留旧元数据；保存成功后再删除旧文件。
8. 旧文件清理失败只记录错误，不回滚已经可用的新产物。

## 前端交互

目标表新增“产物”列，位于“状态”和“操作”之间：

- 无产物时显示“上传产物”。
- 有产物时显示类型图标、文件名和更新时间。
- 点击产物打开侧边面板，不刷新整个页面。
- 面板展示预览、文件信息和原文件下载按钮。
- Owner 和当前部门负责人额外看到“替换”和“删除”；其他用户只读。
- 上传或替换成功后立即更新当前目标行和面板内容。

图片和 PDF 使用浏览器原生预览。Office 文件展示转换后的 PDF。HTML 必须放入无同源权限的沙箱 iframe，禁止访问工作台页面、登录信息和本地存储。

## 错误处理

- 格式、MIME 或大小不符合要求时，在选择文件后和服务端分别提示。
- LibreOffice 未安装、执行超时或转换失败时，明确提示运行依赖或转换错误，旧产物保持不变。
- 文件丢失或损坏时，面板显示“产物暂不可用”，不影响目标列表加载和编辑。
- 无权限操作返回 403；目标不存在返回 404；无效上传返回 400 或 413。
- 删除前要求用户确认；删除失败时保留页面中的现有产物状态。

## 验证与验收

### 自动验证

- 存储模块：随机键、路径边界、写入、读取、删除。
- 文件校验：允许格式、伪造 MIME、超出 20 MB、空文件。
- 权限：当前部门负责人、匹配 Owner、非 Owner、跨部门访问。
- API：首次上传、成功替换、转换失败回滚、下载、预览、删除。
- 目标兼容：旧目标补齐稳定 `id`，无产物目标继续正常编辑。
- 前端：产物列渲染、上传后更新、只读与可编辑操作差异、完成目标缺产物提示。

### 手工验证

- 使用真实 Word、Excel、PPT 文件验证 LibreOffice PDF 预览。
- 验证图片、PDF 和 HTML 的预览及原文件下载。
- 替换期间模拟转换失败，确认旧产物仍可预览和下载。
- 确认产物文件未被 Git 跟踪。

## 运行依赖

开发和运行环境必须安装 LibreOffice，并能从服务端进程调用其无界面转换命令。启动时不强制阻断应用，但首次 Office 上传时若依赖不可用必须返回可操作的错误提示。
