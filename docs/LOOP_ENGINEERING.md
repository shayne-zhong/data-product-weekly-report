# 项目循环工程说明

## 自动循环

项目只保留两个后台循环：周任务结转与报告自动归档。Node 常驻服务是唯一自动调度器；Vercel 只提供页面和 API，不运行后台循环。

## 运行边界

- 发现：Node 启动时立即补偿检查；北京时间每日 08:00–20:00 的整点每小时再次检查。
- 执行：周结转与报告归档调用各自既有领域执行器，不由浏览器加载触发。
- 验证：领域规则只处理到期数据；周结转按“部门 + 源周 + 目标周”防重，报告归档按“部门 + 总结 + 计划归档时刻”防重。
- 持久化：执行中、成功、失败及结果摘要写入业务状态；错误仅保留截断后的可读摘要，不保存密钥、请求头或堆栈。
- 人工检查点：全局管理员可在后台查看最近执行状态并人工补跑；自动循环不得修改归档时间、强制提前归档或绕过任务完成规则。

## 限制与恢复

- 每个循环同一时刻只运行一次，失败不无限重试，等待下一小时或管理员人工补跑。
- Node 停机期间不执行任务；恢复启动后依靠补偿检查追赶漏跑。
- Vercel 不配置 Cron。若未来要启用云端调度，必须重新确认套餐、频率、鉴权和重复投递验证，再更新本说明与 PRD。
